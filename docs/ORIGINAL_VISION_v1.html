02 系統概述 · TL;DR

一段話，加一張組件清單

03 核心不變量 · Invariants

三個不可違反的系統不變量

I1 · 只改 pending
所有 deck 變更僅允許作用於 index > committedIndex 的頁。
保證：改造引擎對違規操作直接 reject
I2 · 需人為批准
任何 patch 進入 live deck 前必經 approval gate。
保證：FSM 中只有 ACCEPT 會 commit
I3 · HUD 不外流
Copilot HUD 於獨立視窗／第二螢幕渲染，分享僅限 tab/window。
保證：開播前 preflight 驗證 displaySurface
不變量在架構層強制執行，而非靠使用者自律——後續各頁說明其落地機制。

05 音訊擷取 · Audio Capture

雙軌擷取：自己的麥克風 + 對方的聲音

  • 麥克風（報告者）：getUserMedia，關閉 echoCancellation 以保真
  • 對方聲音（客戶）：分頁音訊 getDisplayMedia({audio})，或桌面 loopback（Electron desktopCapturer）
  • 混流與分軌：WebAudio 保留雙軌，供 diarization 判斷「誰在說」
  • 取樣封包：AudioWorklet 取 PCM，16kHz／單聲道／~250ms frame，經 WSS 上送
capture.js
// 兩路音訊：本地麥克風 + 對方（分頁）
const mic = await navigator.mediaDevices
  .getUserMedia({ audio:{ echoCancellation:false }});
const far = await navigator.mediaDevices
  .getDisplayMedia({ video:true, audio:true });

// 併軌後送 AudioWorklet 取 16k PCM frame
ctx.createMediaStreamSource(mic)
   .connect(merger, 0, 0);   // ch0 = presenter
ctx.createMediaStreamSource(far)
   .connect(merger, 0, 1);   // ch1 = client
06 語音轉文字 · Streaming ASR

逐句串流轉寫，帶時間戳與說話者

  • 串流式 STT：interim（即時假設）+ final（定稿）雙輸出，數百毫秒回傳
  • VAD / endpointing 自動切句，降低等待
  • 雙軌 diarization：標記 presenter vs. client
  • 輸出時間戳、說話者標記的 segment → 進入分析滾動視窗
transcript segment
{
  "t": 84210,          // ms since start
  "spk": "client",
  "final": true,
  "text": "價格的部分能不能再談？",
  "conf": 0.94
}
interim segment 先到、供 UI 即時顯示；final 才進入分析。
07 理解層 · Analysis

增量分析對話，輸出結構化訊號

  • 對最近 N 輪（rolling window，如 60s / 8 turns）做增量分析
  • LLM 以 structured output 回傳訊號物件（JSON schema 約束）
  • 只處理新 segment，維護 running state，不重算整場
  • 達 confidence 門檻才觸發下游建議
signals (LLM structured output)
{
  "emotion": "hesitant",   // warm|neutral|hesitant|negative
  "interest_topics": ["pricing","onboarding"],
  "buying_signals": ["asked_timeline"],
  "landmines":      ["budget_sensitive"],
  "expansion_ops":  ["multi_team_rollout"],
  "confidence": 0.78
}
08 內容地圖 & 檢索 · Content Map & Retrieval

會前把每頁變成可檢索的知識

會前預處理
  • 每頁 → 摘要 + topic tags + 可延伸方向
  • 產生 embedding，建立 slide graph
  • 寫入向量庫（pgvector），供會中查詢
會議中檢索
  • 以當前 signals 組 query embedding
  • cosine 相似度取 top-k 候選後續頁
  • re-rank 後作為生成 grounding（RAG）
signals → query_embed → vector_search(top_k) → rerank → {既有頁候選 | 生成 prompt}
09 改造引擎 · Adaptation Engine

只在 pending 尾段做 INSERT / REPLACE / REORDER

Deck model：有序 slides、committedIndex（最後播出頁）、pending = index > committedIndex。
  • INSERT_AFTER(i) — 僅限 i > committed
  • REPLACE(i) — 僅限 i > committed
  • REORDER — 僅在 pending 區間內
  • 來源：檢索既有頁 ／ LLM 生成新頁（grounded）
guard — 強制 I1
function applyPatch(op) {
  if (op.index <= deck.committedIndex) {
    return reject("I1: cannot touch shown slide");
  }
  if (!op.approvedBy) {
    return reject("I2: needs presenter approval");
  }
  deck.pending = patch(deck.pending, op);
}

11 防漏餡 · Surface Isolation

從 getDisplayMedia 層級杜絕整螢幕外洩

  • 只允許 tab/window：以 constraints 隱藏「整個螢幕」選項
  • 開播前 preflight：讀 displaySurface，若為 monitor 即中止
  • HUD 隔離：Copilot 面板在獨立 BrowserWindow／第二螢幕，不在被擷取的 tab DOM 內
  • 安全分享模式：未通過檢查不允許開始播放
share-guard.js
const stream = await navigator.mediaDevices.getDisplayMedia({
  video: { displaySurface: "browser" },
  monitorTypeSurfaces: "exclude",   // 移除整螢幕選項
  selfBrowserSurface: "exclude"
});
const s = stream.getVideoTracks()[0].getSettings();
if (s.displaySurface === "monitor") {
  stream.getTracks().forEach(t => t.stop());
  throw Error("I3: whole-screen share blocked");
}

13 資料處理 · Data & Privacy

預設最小化、可稽核、可刪除

同意閘門 — session 開始需取得錄音／分析同意，未同意不啟動擷取。
PII 遮蔽 — transcript 落地前去識別化（姓名、電話、卡號等）。
保留策略 — 預設記憶體內、會後即棄；持久化為 opt-in 且設 TTL。
傳輸與儲存 — WSS/TLS 傳輸、at-rest 加密；資料僅於本地與授權雲端流動。
存取控管 — 逐字與洞察採 RBAC，僅授權人員可讀。
